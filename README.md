# BypassDPI-WPF

Неофициальный форк [NetFix](https://github.com/rupleide/NetFix) — GUI-оболочки для обхода блокировок Telegram и Discord под Windows на базе проектов [Flowseal](https://github.com/Flowseal).

> **ВНИМАНИЕ!** Это неофициальная сборка. Оригинальный автор (rupleide) не имеет отношения к ней, не гарантирует её безопасность и не оказывает поддержку. Оригинальный проект: [github.com/rupleide/NetFix](https://github.com/rupleide/NetFix).

## Что изменено в форке

- Удалён Discord Rich Presence и вся реклама/ссылки в статусе Discord.
- Убрано автоматическое открытие Telegram (`tg://proxy…`) при запуске TgWsProxy — прокси запускается в фоне, окно подключения в Telegram больше не всплывает.
- Главная кнопка стала переключателем: первый клик запускает службы, второй — останавливает их.
- Полностью удалена встроенная ритм-игра и все связанные с ней вкладки, ресурсы и упоминания.
- Запуск можно отменить на этапе подготовки: главная кнопка и диалог проверки становятся «Отмена».
- Добавлена стандартная кнопка «Развернуть / Восстановить», заголовок можно разворачивать двойным кликом; лог растягивается вместе с окном.
- Убрана молния слева от «Сервисы», добавлена собственная иконка приложения.
- Уведомление о неофициальном характере сборки показывается при первом запуске.
- Соблюдены дополнительные условия GPL-3.0 Section 7 исходного проекта (см. ниже).

## Требования

- Windows 10 / 11 (x64).
- Запуск от имени администратора — нужен драйвер WinDivert.
- [.NET Desktop Runtime 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) (windowsdesktop-runtime 8.0.x x64).

Сторонние компоненты (Zapret, TgWsProxy) в репозитории не хранятся: приложение скачивает их напрямую с репозиториев авторов:

- [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
- [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)

## Сборка из исходников

```powershell
git clone https://github.com/vitaliyDrovosek/BypassDPI-WPF.git
cd BypassDPI-WPF
dotnet build BypassDPI-WPF.csproj -c Release -p:Platform=x64
```

Готовый бинарник: `bin/x64/Release/net8.0-windows/BypassDPI-WPF.exe`.
